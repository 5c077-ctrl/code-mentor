**Code Mentor PRO** is an enterprise-grade, multi-platform interactive software engineering and programming platform inspired by modern developer learning hubs. It combines structured 2-digit numbered lectures, 15+ in-browser compiler sandboxes, real-time quizzes, verifiable certificates, and integrated AI assistant APIs for code explanations and debugging.

## ✨ Key Features

- 🔢 **Sequential 2-Digit Numbered Sublessons (`01`, `02`, `03`...)**: Standardized lecture numbering across all courses, eliminating indexing errors and ensuring structured step-by-step learning.
- 🏷️ **Lecture Count Badges**: Visual badges (`• 39 Lectures`, `• 17 Lectures`, `• 29 Lectures`) across category cards and course detail headers.
- ⚡ **Multi-Language Online Compilers (`/compilers`)**: 15+ in-browser code sandboxes with live execution for Python, Java, C++, C, PHP, Kotlin, Go, JavaScript, TypeScript, Ruby, Rust, SQL, Swift, Elixir, and Bash Shell.
- 📚 **10+ Curated External Resources per Topic**: Every course includes 10+ external references: YouTube full courses, official documentation, official notes, free eBooks, cheat sheets, and in-depth articles.
- 🤖 **AI Code Assistance APIs**: Integrated Gemini AI API (`google-generative-ai`) and Anthropic Claude API for real-time hint generation, code review, and interactive tutoring.
- 🧪 **Interactive Quizzes & Instant Validation**: End-of-lecture quizzes with Multiple Choice Questions (MCQ) and True/False checks.
- 🏆 **Gamification & Certificates**: XP points, daily login streaks, leaderboard rankings, and downloadable PDF certificates.
- 📴 **100% Offline Capability**: All course curricula, sublessons, quizzes, and client-side sandboxes run locally without internet.
- 💻 **Desktop Executable (.exe)**: Standalone Windows desktop app packaged with Electron.
- 📱 **Mobile Hotspot & Tunneling Support**: Built-in `npm run dev:host` and `npm run tunnel` commands to test seamlessly on mobile devices.

## 🚀 Getting Started & CLI Commands

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/your-username/code-mentor-pro.git
cd code-mentor-pro
npm install
```

### 3. Environment Configuration
Create a `.env` file in the root directory:
```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="your-super-secret-jwt-key"
GEMINI_API_KEY="your-gemini-api-key"
ANTHROPIC_API_KEY="your-anthropic-api-key"
```

### 4. Database Setup & Seeding
Populate the database with all 11 categories, 40+ courses, 60+ modules, and 150+ sublessons:
```bash
npx prisma db push
npx tsx prisma/seed.ts
```

### 5. Running the Application

#### A. Standard Local Web Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

#### B. Mobile Hotspot Access
```bash
npm run dev:host
```
Listens on `http://0.0.0.0:3000` so devices on your Wi-Fi/Hotspot can connect directly via your PC's IP address (e.g. `http://172.20.10.6:3000`).

#### C. Instant Public Mobile Tunnel
```bash
npm run tunnel
```
Creates a public HTTPS URL (via `localtunnel`) to open the app on your mobile phone anywhere without firewall configuration.

#### D. Package Windows Desktop Executable (.exe)
```bash
npx electron-builder --win --x64
```
Generates the standalone portable executable inside `dist/win-unpacked/electron.exe`.
